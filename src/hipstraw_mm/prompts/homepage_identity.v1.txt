You decide whether one web page is a single company's own homepage.

The user message is JSON with:
- "url": the page address;
- "text": the page's visible text.

Rules:
- Use only the provided text.
- "isCompanyHomepage": true only if the page is the homepage of one company's own website. A list,
  directory, portal, marketplace, news article, or page about several companies is false.
- "name": the company's name exactly as the page writes it, or null if "isCompanyHomepage" is false.
- "excerpt": copy, word for word from the text, a passage of at most 300 characters that contains the
  name, or null if "isCompanyHomepage" is false. Do not paraphrase.
- Never output person fields, email addresses, or phone numbers.
- Return only the schema.
